# Changelog

All notable public changes to StatusPerch are documented here.

## [1.0.1] — 2026-09-19

- Restored menu-bar collection on macOS 27 using bounded native status items compatible with the new layout.
- Added support for wide and mixed-display setups without Screen Recording, Accessibility access, or private APIs.
- Added a one-time bilingual upgrade guide for arranging the divider and chevron on macOS 27.
- Kept the existing behavior unchanged on macOS 13–26.

See the [full 1.0.1 release notes](docs/release-notes/v1.0.1.md).

## [1.0.0] — 2026-08-30

- Initial public release.
- Native menu-bar collection boundary and hide/show control.
- Command-drag ordering and optional automatic hiding.
- Launch at login.
- English and Simplified Chinese interface.
- Automatic Light/Dark appearance.
- Universal 2 support for Apple silicon and Intel Macs.
- Fully local operation without Screen Recording or Accessibility permission.

See the [full 1.0.0 release notes](docs/release-notes/v1.0.0.md).
