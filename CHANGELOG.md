# Changelog

All notable public changes to StatusPerch are documented here.

## [1.0.0] — 2026-08-30

- Initial public release.
- Native menu-bar collection boundary and hide/show control.
- Command-drag ordering and optional automatic hiding.
- Launch at login.
- English and Simplified Chinese interface.
- Automatic Light/Dark appearance.
- Universal 2 support for Apple silicon and Intel Macs.
- Fully local operation without Screen Recording or Accessibility permission.

See the [full 1.0.0 release notes](docs/release-notes/v1.0.0.md).
