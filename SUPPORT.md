# Support

Before opening an issue:

1. Read the [English troubleshooting guide](docs/user-manual/en/4-troubleshooting.md) or [简体中文故障排查](docs/user-manual/zh-Hans/4-troubleshooting.md).
2. Confirm that you installed the latest release from this repository.
3. Temporarily quit other menu-bar managers to rule out competing layout behavior.
4. Note your StatusPerch version, macOS version, Mac model/architecture, display arrangement, and exact reproduction steps.

Use the [bug report](https://github.com/qingtan-labs/StatusPerch/issues/new?template=bug_report.yml) or [feature request](https://github.com/qingtan-labs/StatusPerch/issues/new?template=feature_request.yml) form. Do not post passwords, API keys, private screenshots, or security-sensitive details.

Support is provided on a reasonable-effort basis with no guaranteed response time.
