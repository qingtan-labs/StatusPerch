# StatusPerch 1.0.0

Initial public release for macOS 13 and later.

## Highlights

- Collect low-frequency menu-bar items behind a native boundary.
- Click to hide/show; Command-drag to arrange.
- Auto-hide after 5, 10, or 30 seconds.
- Launch at login with safe fallback behavior for the current ad-hoc build.
- English, Simplified Chinese, and Follow System language options.
- Native Light/Dark adaptation and VoiceOver state labels.
- Universal 2 support for Apple silicon and Intel.
- Offline operation with no Screen Recording or Accessibility permission.
