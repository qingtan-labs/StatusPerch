# StatusPerch 1.0.0

适用于 macOS 13 及更高版本的首次公开发行版。

## 主要功能

- 使用原生收纳边界隐藏低频菜单栏图标。
- 点击收起/展开，按住 Command 手动排列。
- 支持 5、10、30 秒自动收起。
- 支持登录启动，并为当前 ad-hoc 构建提供安全兼容方案。
- 支持跟随系统、English 和简体中文。
- 自动适配亮色/暗色，并提供 VoiceOver 状态标签。
- Universal 2，同时支持 Apple 芯片与 Intel。
- 完全本地，不需要屏幕录制或辅助功能权限。
