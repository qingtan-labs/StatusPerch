# StatusPerch 1.0.1

Released: September 19, 2026

## What changed

- Restores collection on macOS 27 using bounded native status items compatible with Apple's redesigned menu bar.
- Supports built-in, wide, and mixed-display setups without Screen Recording, Accessibility permission, or private system interfaces.
- Keeps the existing behavior unchanged on macOS 13–26.
- Improves collapsed-state restoration, display-change handling, and local geometry diagnostics.

## macOS 27 upgrade note

After installing 1.0.1, hold Command and arrange the menu bar once from left to right:

`items to collect → divider → StatusPerch chevron → clock/frequent items`

When collapsed, the selected items move into macOS 27's native `«` overflow area. Click the StatusPerch chevron again to restore them.

The native `«` control and the empty displacement span are expected on macOS 27. Put always-visible system items to the right of the StatusPerch chevron.

# StatusPerch 1.0.1 中文发布说明

发布日期：2026 年 9 月 19 日

## 本次更新

- 修复 macOS 27 重构菜单栏后无法收纳的问题，改用符合新布局限制的多个原生状态项。
- 兼容内建屏幕、宽屏和不同宽度的多显示器组合，不需要屏幕录制、辅助功能权限或非公开系统接口。

## macOS 27 升级提示

安装 1.0.1 后，请按住 Command，从左到右重新排列一次：

`待收纳图标 → 小竖线 → StatusPerch 箭头 → 时钟/常用图标`

收起后，选中的图标会进入 macOS 27 原生的 `«` 溢出区域；再次点击 StatusPerch 箭头即可恢复。

macOS 27 下出现系统 `«` 控件和用于推动图标的空白区域属于正常表现。请将需要常驻的系统图标放到 StatusPerch 箭头右侧。
