# StatusPerch 1.0.1

Released: September 19, 2026

## What changed

- Restores collection on macOS 27 using bounded native status items compatible with Apple's redesigned menu bar.
- Supports built-in, wide, and mixed-display setups without Screen Recording, Accessibility permission, or private system interfaces.
- Keeps the existing behavior unchanged on macOS 13–26.
- Improves collapsed-state restoration, display-change handling, and local geometry diagnostics.
- Adds Compact, Standard, and Extended collection ranges. Extended is the recommended default so crowded menu bars are fully collected; Standard and Compact provide optional shorter spans.
- Adds a visual setup guide and a restart prompt when a newly connected wider display needs more prepared collection capacity.
- Adds **Software Update** with a switchable weekly check and an immediate manual check. New stable releases download directly after confirmation and open from Downloads; no GitHub web page is required.
- Choosing **Not Now** suppresses further automatic prompts for that release. Offline automatic checks remain silent.
- Adds **Report an Issue…**, which opens the public GitHub issue forms without automatically uploading device information.

## macOS 27 upgrade note

After installing 1.0.1, hold Command and arrange the menu bar once from left to right:

`items to collect → divider → StatusPerch chevron → clock/frequent items`

When collapsed, the selected items move into macOS 27's native `«` overflow area. Click the StatusPerch chevron again to restore them.

The native `«` control can still appear on macOS 27. Put always-visible system items to the right of the StatusPerch chevron. If some collected icons remain visible, right-click the chevron and choose **Collection Range → Extended**.

# StatusPerch 1.0.1 中文发布说明

发布日期：2026 年 9 月 19 日

## 本次更新

- 修复 macOS 27 重构菜单栏后无法收纳的问题，改用符合新布局限制的多个原生状态项。
- 兼容内建屏幕、宽屏和不同宽度的多显示器组合，不需要屏幕录制、辅助功能权限或非公开系统接口。
- macOS 13–26 继续使用原有逻辑，不改变现有行为。
- 改进收起状态恢复、显示器变化处理和本地布局诊断。
- 新增“紧凑、标准、扩展”三档收纳范围；默认推荐“扩展”以确保拥挤菜单栏能完整收起，“标准”和“紧凑”作为可选的较短范围。
- 增加图示化排列引导；连接更宽显示器并需要更多收纳容量时，会直接提示重新启动。
- 新增“软件更新”：默认每周低频检查，也可随时手动检查；确认后直接下载并打开安装窗口，无需跳转 GitHub 网页。
- 选择“暂不升级”后，该版本不再自动提醒；断网时自动检查保持静默。
- 新增“问题反馈…”，直接打开公开 GitHub Issue 表单，且不会自动上传设备信息。

## macOS 27 升级提示

安装 1.0.1 后，请按住 Command，从左到右重新排列一次：

`待收纳图标 → 小竖线 → StatusPerch 箭头 → 时钟/常用图标`

收起后，选中的图标会进入 macOS 27 原生的 `«` 溢出区域；再次点击 StatusPerch 箭头即可恢复。

macOS 27 下仍可能出现系统 `«` 控件。请将需要常驻的系统图标放到 StatusPerch 箭头右侧；如果收起后仍有图标可见，请右键箭头并选择“收纳范围 → 扩展”。
