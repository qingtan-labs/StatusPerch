# 快速上手与日常使用

## 首次排列

1. 启动 StatusPerch。
2. 按住 Command 键。
3. 把小竖线拖到需要收纳图标的右侧。
4. 保持 StatusPerch 箭头紧邻小竖线右侧。
5. 时钟和高频系统控件放在箭头右侧。

建议顺序：

`低频应用 → 小竖线 → 箭头 → 时钟和系统控件`

顺序由 macOS 保存。StatusPerch 不读取其他图标的名称或内容。

## 收起与展开

- 点击箭头收起小竖线左侧的图标。
- 再次点击箭头展开。
- 右键箭头打开设置。
- 点击小竖线也可打开设置。
- 按住 Command 可移动两个 StatusPerch 控件。

## 手动重排

先展开，按住 Command，再把任意菜单栏图标拖到希望的位置。StatusPerch 不会替用户自动排序。

## 安全退出

从菜单中选择“退出 StatusPerch”。退出前应用会恢复展开宽度，让被收纳的图标重新显示。

## 多显示器

箭头和小竖线必须位于同一条菜单栏。如果它们分散到不同显示器或顺序颠倒，应用会警告而不是继续收起。
