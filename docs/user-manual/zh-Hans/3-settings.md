# 设置说明

右键箭头或点击小竖线即可打开设置。

## 收起 / 展开

第一项会根据当前状态变化，与直接点击箭头效果相同。

## 整理并重排图标

先展开全部收纳图标，再显示排列说明。重排时需要按住 Command。

## 收纳范围

在 macOS 27 中，可以选择图标收起时使用的空间：

- **紧凑**：适合少量图标，产生的空白最短。
- **标准**：在收纳能力和空白长度之间取得平衡。
- **扩展（推荐）**：启用为宽屏和拥挤菜单栏预留的额外安全状态项。

图标收起时仍可能出现 macOS 原生的 `«` 溢出按钮。

## 展开后自动收起

- 关闭：保持展开，直到再次点击箭头。
- 5 / 10 / 30 秒：到达选定时间后自动收起。

当菜单打开、StatusPerch 弹窗显示或鼠标仍在菜单栏时，计时器会等待，避免中断操作。

## 登录时自动启动

用于开启或关闭登录启动。应用优先使用 macOS 标准登录项。未使用 Developer ID 的版本可能显示“兼容模式”，表示使用当前用户范围的 LaunchAgent。“等待系统批准”表示需要在系统设置中确认。

## 语言

- 跟随系统。
- English。
- 简体中文。

切换后菜单、工具提示、弹窗和 VoiceOver 标签立即更新。

## 外观

无需单独设置主题。菜单和模板图形会自动适配 macOS 亮色和暗色外观。
