# 常见问题

## StatusPerch 会录制屏幕吗？

不会，也不会申请屏幕录制权限。

## 需要辅助功能或输入监控吗？

不需要。图标排序使用 macOS 原生的 Command 拖动行为。

## 会联网吗？

不会。1.0.0 没有账号、统计、广告、联网更新或云服务。

## 能自动识别并排序其他应用的图标吗？

不能。macOS 没有提供对应的公开接口，StatusPerch 也不会使用侵入式替代方案。

## 能显示第二行系统菜单栏吗？

不能。同类产品显示的“第二行”通常是独立悬浮面板，不是系统菜单栏换行。

## 小竖线有什么作用？

它是收纳边界。需要收纳的图标放在左侧，箭头和常驻图标放在右侧；其宽度也是实现收起与展开的机制。

## 为什么程序坞没有图标？

StatusPerch 是菜单栏辅助应用。通过菜单栏箭头或小竖线打开设置和退出。

## 是否开源？

不是。公共仓库只包含文档和发布安装包，应用与品牌采用专有免费软件许可。
